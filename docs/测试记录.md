# 验证范围

测试仅使用脚本生成的合成视频、音频与字幕，不包含私人媒体、设备标识或使用记录。

自动化覆盖设置迁移与持久化、历史并发合并、原子文件替换、播放队列、续播、字幕、静音、截图与正常关闭。真实桌面测试需要显式开启，未运行的项目明确跳过。

0.1.2.1 新增“跟随视频比例”设置，默认开启。旧配置中没有此字段时也使用开启状态；关闭后保留上次窗口比例。窗口模式的真实界面验证和最终云端计数见版本发布说明。

性能优化减少主页刷新、队列重复构建，并将历史写入和目录扫描移出界面线程。没有对照性能基准，不声称具体帧率或内存提升百分比。

设备重置、长时间浸泡、NAS、原生 HDR 输出及全部辅助功能路径尚未完整验收。
