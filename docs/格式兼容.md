# 格式兼容

结论只来自 2026-10-28 的本地样本。扩展名本身不算支持。没有样本的格式写成未验证。

「自动化」表示 `FileOpensAndAdvances` 通过：文件被 libmpv 打开，时间向前走或到达结尾，并且没有错误标题。

「窗口」表示 `SPlayer.exe --smoke` 在真实 SwapChainPanel 上呈现了帧，或对纯音频推进了播放位置。

## 未验证

这些格式没有可解码的本地样本，不能写成支持：

- VC-1。所用 ffmpeg 没有 VC-1 编码器。
- HDMV PGS。所用 ffmpeg 没有 pgssub 编码器。
- Ogg Theora / OGV。所用 ffmpeg 没有 libtheora。音频 Ogg Vorbis 已测。
- RealVideo rv40。已测的是 rv20，装在 `.rm` 和 `.rmvb` 里。
- 真实蓝光原盘菜单和 DRM。
- 正在服务的 NAS 或 SMB。代码把 UNC 和网络盘符当成网络路径，不断开时不会误报「找不到文件」。没有在断线的服务器上播放。
- 用户输入的 HTTP/HTTPS。内核选项开了，分类测试通过，没有架服务器播放。

DVD 菜单、Blu-ray 菜单和受保护的媒体不在支持范围内。
